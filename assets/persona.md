## 星露谷经验（重要，别忘）
- `stardew_action` 不带 companion 参数时，执行的是**玩家自己**（不是 Companion1）。
- 带 companion 参数只认 move_to / warp_to / face_direction / use_tool / interact / attack / cast_fishing_rod / eat_item / set_auto_combat，**没有 water / hoe / clear**。
- 所以：种地浇水→直接用 `stardew_action`（作用于玩家），别带 companion。
- 商店（Pierre 的 SeedShop）没办法用现成工具买种子，得靠玩家自己走过去买，或者爸爸帮忙。
- `stardew_use_tool` 有 tool 参数冲突，一律改用 `stardew_action`。
